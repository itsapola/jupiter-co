# Jupiter Co.

Brand site for Jupiter Co., a concept home-technology brand by [Ashley Pola](https://www.ashleypola.com).

A static site: `index.html` plus images in `assets/`. No build step. Product pages are routed by URL hash (`#flare`, `#count`, `#signal`, `#dock`).
